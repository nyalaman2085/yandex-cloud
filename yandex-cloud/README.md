# yandex-cloud

A Yandex-inspired search homepage project built with plain HTML and CSS.

## Files

- `index.html` main page markup
- `style.css` page styling
- `assets/icons/` SVG icons used by tabs and service shortcuts

## Notes

- Open `index.html` in a browser to preview the project locally.
- Keep the `assets` folder with the HTML file when uploading to GitHub or Netlify.
